# Library Inventory Manager – Mini Project

This is my mini project for the Python subject (Programming for Problem Solving).  
I made a simple Library Inventory System using basic OOP concepts.

The program runs fully in the terminal and helps in managing books like:

- Adding a new book
- Issuing a book
- Returning a book
- Searching for a book
- Viewing all books
- Saving book details in a JSON file

The code is simple so that any beginner can understand it.

## Files in the Project

1. Book.py  
   - Contains the Book class  
   - Stores book title, author, isbn and status  
   - Has functions to issue and return a book

2. inventory.py  
   - Manages the complete list of books  
   - Loads and saves data from books.json  
   - Has functions to add, search and show books

3. main.py  
   - The main file which runs the menu  
   - User can choose options like Add, Issue, Return, etc.

Note: The file **books.json** is created automatically when you run the program.

## How to Run

Make sure all three Python files are in the same folder.

Then open terminal and type:
python3 main.py
(or just `python main.py` depending on your system)

## Features

- Simple menu-based system  
- Uses Object-Oriented Programming  
- Stores data permanently in JSON  
- Easy to understand only using basics  
- No extra Python libraries required
